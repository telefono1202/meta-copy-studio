# 留白 Copy Studio · 單機版

## GitHub Pages 公開網頁

儲存庫已在 main 根目錄提供 index.html 與 .nojekyll，無需建置。

在 GitHub 的 Settings → Pages 中，選擇 Deploy from a branch、main、/(root)，然後 Save。待 GitHub Pages 建置完成後，以頁面顯示的網址開啟。

此儲存庫的預期 Pages 網址為 https://telefono1202.github.io/meta-copy-studio/ 。只有啟用並完成部署後才可使用。私人儲存庫是否支援 Pages 取決於 GitHub 方案；若目前方案不支援，需由擁有者決定升級方案或將儲存庫改為公開。

網站內容為靜態文案工具；不需要 GitHub Token 或其他密鑰。離線模板與規則檢測可直接使用；Ollama 仍需使用者自己的本機服務與瀏覽器連線權限。

下載 index.html，使用 Chrome、Edge、Safari 或 Firefox 開啟即可。無需安裝套件、帳號或 API Key。所有樣式與程式內嵌，離線可用，不依賴 CDN。

## 使用

1. 選「產生文案」「檢測文案」或「保留 Hook 改寫」。
2. 填寫療程、故事線或原文；有核實資訊及素材描述可一起填入。
3. 預設離線模式：產生模式是模板編排，檢測是規則比對，改寫是刪修與另稿模板，不是真正的自由語意生成。
4. 結果可複製或下載 TXT。亦可「複製 AI 指令」貼到原對話中深化創意。
5. 任何輸入變更後舊結果會失效，以免匯出與新輸入不符的內容。

## 選用本機 AI

自行安裝 Ollama（https://ollama.com），例如執行 `ollama pull qwen3:8b`（下載需網路與足夠硬體），確認服務啟動。在工具中選「本機 AI · Ollama」，輸入你已安裝的模型名稱。模型完成下載後可在本機運行。此功能沒有在交付環境連接真實模型驗證。

瀏覽器可能因來源限制阻擋 file:// 連線。建議用 Python 在工具所在資料夾執行：

```
python -m http.server 8765 --bind 127.0.0.1
```

瀏覽 http://127.0.0.1:8765 。如有來源限制，Ollama 啟動環境的 OLLAMA_ORIGINS 可僅設定為 http://127.0.0.1:8765，再重啟 Ollama。不要為此開放全部網域。安裝版 Ollama 的環境變數設定方式依作業系統而異。Ollama 服務通常使用 http://localhost:11434。
